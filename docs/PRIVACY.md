# GameCrash Kit v0.1 隐私承诺与脱敏边界规范

> 本文档固化 [SPEC_v0.1.md](SPEC_v0.1.md) 第 3 节与第 6 节的隐私保护约束，作为代码实现、单元测试断言及发布审计的强制依据。

## 1. 运行期与存储零留痕承诺

1. **零网络出站**：应用在扫描、解析、渲染及导出期间不发起任何 HTTP/TCP/UDP 网络请求，无自动更新与无遥测上报。
2. **零默认持久化**：扫描结果、原始事件 XML 与日志缓冲仅驻留当前会话内存；扫描结束即清理原始缓冲引用，窗口关闭即全部释放。不写入历史数据库或注册表。
3. **只读采集**：唯一磁盘写入行为为用户主动点击「保存」并确认路径后的导出文件（PNG 或 Markdown）。
4. **不碰转储内存**：永不读取、打包或导出 `.dmp` 内存转储内容。

## 2. 双层分享隐私模型

所有对外输出（剪贴板 Markdown 与 PNG 急诊单）均由同一份不可变 `ShareReportModel` 生成，并遵循「默认严格白名单 + 二次确认可选脱敏摘要」双层隔离：

### 2.1 默认层：严格字段白名单（Strict Whitelist）

默认模式下，**任何原始 XML、任意自由文本、绝对路径、启动命令行、Report ID、完整调用栈、SID、IP、用户名与计算机名均不进入 `ShareReportModel`**。

允许进入默认白名单的字段仅限：
* 软件版本号与规则集版本号（`appVersion`、`rulesetVersion`、`schemaVersion`）
* 事故摘要三元组：程序名（可勾选隐藏为 `<APP>`）、故障模块名、规范化异常码（如 `0xc0000005`）
* 脱敏后的可区分路径后缀（仅用于同名程序消歧，不含盘符根目录与用户目录）
* 事故时间（可勾选隐藏精确时间，仅保留日期与相对时间差）
* 版本化规则命中结论（`RuleId@Version`、归属强度、证据强度、模板化陈述与下一步建议）
* 中性环境事实摘要（OS 版本族与构建号、GPU 名称与驱动发布日期、VC++ 运行库状态、页面文件总量状态、系统区域代码页与 HVCI 状态、扫描瞬间运行中的常见覆盖层名称）
* 来源覆盖状态（已扫描范围、截断/跳过/无权限提示）

### 2.2 可选层：二次确认脱敏报错摘要（Opt-in Scrubbed Excerpt）

* **默认关闭**：仅当存在结构化提取的引擎错误行或核心错误字段时，预览抽屉才提供勾选框「附带受限脱敏报错摘要」。
* **长度硬上限**：最多 **5 行**、总长不超过 **600 字符**，严禁携带完整调用栈或启动参数。
* **强制擦除管线**：进入预览前必须替换本机用户名（`<USER>`）、计算机名（`<PC_NAME>`）、`%USERPROFILE%` 路径（`<USER_HOME>\`）、Windows SID（`<SID>`）、IPv4/IPv6（`<IP>`）、邮箱（`<EMAIL>`）、17 位 Steam64 ID（`<STEAM_ID>`）、常见 Token/Key 参数及控制字符。
* **所见即所得**：用户必须在预览区看到脱敏后的实际文本后再主动点击复制或保存；Markdown 预览与剪贴板内容逐字一致，PNG 预览与保存文件为同一份图像。
