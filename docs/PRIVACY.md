# GameCrash Kit v0.2 隐私承诺与脱敏边界规范

> 本文档定义 `GameCrash Kit` 自 `v0.1` 延续至 `v0.2` 的运行时零留痕、文件读取与双层脱敏约束，作为代码实现、单元测试断言及发布审计的强制依据。

## 1. 运行期与存储零留痕承诺

1. **零网络出站**：应用在扫描、解析、渲染及导出期间不发起任何 HTTP/TCP/UDP 网络请求，无自动更新与无遥测上报。
2. **零默认持久化**：扫描结果、原始事件 XML 与日志缓冲仅驻留当前会话内存；扫描结束即清理原始缓冲引用，窗口关闭即全部释放。不写入历史数据库或注册表。
3. **只读采集与防覆盖保护**：唯一磁盘写入行为为用户主动点击「保存」并确认路径后的导出文件（PNG 或 Markdown）；保存前通过 Win32 `GetFileInformationByHandle` 比对底层卷序列号与文件索引，严禁通过路径别名或硬链接覆盖当前已加载的取证源日志。
4. **不碰转储内存与远程目录**：入口即直接拒绝 `.dmp`/`.mdmp`/`.hdmp` 内存转储；任何路径存在性检查前优先校验证祖先重解析点、UNC 与非固定盘，永不触发隐藏远程/SMB 目录探测。

## 2. 双层分享隐私模型

所有对外输出（剪贴板 Markdown 与 PNG 急诊单）均由同一份不可变 `ShareReportModel` 生成，并遵循「默认严格白名单 + 二次确认可选结构化信号摘要」双层隔离：

### 2.1 默认层：严格字段白名单（Strict Whitelist）

默认模式下，**任何原始 XML、任意自由文本（含 `SourceCoverage.Detail` 原始错误串或 `EngineVersion` 私有分支名）、绝对路径、启动命令行、Report ID、完整调用栈、SID、IP、用户名与计算机名均不进入 `ShareReportModel`**。

允许进入默认白名单的字段仅限：
* 软件版本号与规则集版本号（`appVersion`、`rulesetVersion`、`schemaVersion`）
* 事故摘要元组：程序名或日志格式标签（可勾选隐藏为 `<APP>` / `<已隐藏>`）、故障模块名（隐藏程序名时同步掩码同名模块为 `<APP_MODULE>`）、规范化异常码或命中固定信号标记、安装来源粗粒度分类（或手选日志致命性/Windows 扫描状态）
* 扫描范围与采集受限边界说明（仅使用相对扫描时长、过滤模式、枚举映射的受限/截断模板，绝不携带精确起止时钟或原始系统异常详情）
* 事故时间或手选文件修改时间（可勾选隐藏精确时间，仅保留日期与相对时间差）
* 版本化规则命中结论（`RuleId@Version`、归属强度、证据强度、模板化陈述与下一步建议）
* 中性环境事实摘要（OS 版本族与构建号、GPU 名称与驱动发布日期、VC++ 运行库状态、页面文件总量状态、系统区域代码页与 HVCI 状态、扫描瞬间运行中的常见覆盖层名称）
* 来源覆盖状态（本地化状态与读取条数）

### 2.2 可选层：二次确认固定结构化日志信号摘要（Opt-in Structured Signal Summary）

* **默认关闭**：仅当手选日志提取到有效结构化状态或固定错误信号时，预览抽屉才提供勾选框「附带固定结构化日志信号摘要」。
* **零原文出口**：勾选后**仅输出由规则化字段生成的固定模板行**（日志格式、致命性状态、剥离私有分支/提交串后的前导数字版本号、闭合白名单 RHI 枚举、命中的固定图形/OOM 标记及读取截断提示），**绝不输出原始日志正文或任意自由报错行**。
* **强制擦除管线**：进入预览与导出前仍须经过 `PrivacyScrubber` 统一擦除本机用户名（含双字中文名）、计算机名、用户目录、`SID`、IPv4/IPv6、邮箱、Steam64/SteamID3/Legacy ID、带引号账号凭据、可选时钟 `<TIME>` 及控制字符。
* **所见即所得与剪贴板隔离**：Markdown 预览与剪贴板内容逐字一致，复制至 Windows 剪贴板时附加禁用云剪贴板与历史记录标记；PNG 预览与保存文件为同一份 900px 浅底图像。
